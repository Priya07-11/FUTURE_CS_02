# FUTURE_CS_02

This repo captures my hands-on journey during my internship at Future Interns, where I monitored security alerts and responded to incidents using Splunk Enterprise and the botsv3 dataset. I tracked down real attacks like SSH brute-force, failed Windows logins, risky cloud access without MFA and suspicious DNS queries. Along the way, I learned how to spot threats, analyze logs and recommend practical fixes. The report includes all my findings, screenshots and mitigation steps. Looking back, it’s been an amazing experience sharpening my cybersecurity skills.
